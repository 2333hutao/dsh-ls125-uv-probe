# LS125 紫外辐照计 / UVALED-X3 探头 —— 协议逆向与自制主机工程

一个**自包含**的工程包：把"林上 LS125 紫外辐照计 + UVALED-X3 探头"之间的私有通信协议
完整逆向出来，并用一块自制 STM32F103 当主机读它 —— **完全脱离原装表**。

## 结论先行

| 能力 | 状态 | 证据 |
|---|---|---|
| 读**实时辐照度** | ✅ | 与表显最大值**三轮逐位吻合**（µW/cm²，÷1000 = mW/cm²） |
| 读**累积能量** | ✅ | `d(能量)/dt == 辐照度`；清零后从 0 累加；量级吻合 |
| 读**平均值** | ✅ | 稳态下与实时值相等（差 0.4%） |
| 读**最小值** | ✅ | 清零后跳成当前读数；长期为 0 时与表显 `P_MIN 0.0000` 一致 |
| 读**距上次清零时间** | ✅ | 每帧 +5，LSB = 0.1 s；**表上就有这个显示** |
| **远程清零** | ✅ | `AB 21 20 00 02 00 01 00 3D 8A`，自制 MCU 复现成功 |
| 校验 | ✅ | **CRC-16/MODBUS**，双向同款，穷举 65536 多项式唯一命中 |
| 自制主机端到端 | ✅ | F103：**21/21 帧、零 CRC 错、零超时**，数值自洽 |

**探头不需要原装表**：只发一条恒定的轮询命令，它就会以 500 ms 周期回报数据。

## 硬件

**探头线 6 芯**：5V、2×GND（供电地与信号地相通）、3 根信号。

| 信号 | 方向 | 说明 |
|---|---|---|
| D0 | 主机 → 探头 | 轮询/命令（9600 8N1） |
| D2 | 探头 → 主机 | 28 字节数据帧 |
| D4 | — | 静态控制线，**可悬空**（与复位/清零无关，四重实验否定） |

**自制主机接线**：TX→主机→探头线、RX→探头→主机线、GND 共地、5V 供电、D4 悬空；
**原装表必须拔掉**。

**监听（并联嗅探）接线**：LA 的 GND 必须接被测系统的地；CH0/CH2/CH4 分别夹三根信号；
LA 输入高阻，并联不影响通信。

## 这个工程包是怎么来的（时间线）

1. **卡在"逻辑分析仪打不开"** —— 排查驱动/接线/固件/换口全部无效；
   最终定位为 sigrok 静态链接的 2016 年 libusb 内部派发 bug（详见 `AGENTS.md` 坑 1）。
2. **自研抓取工具** `fx2cap.cjs`（官方 libusb 1.0.27 + 从 sigrok 源码抠出的 fx2lafw 协议），
   并顺手实现 sigrok 没有的两个能力：**无 3.5 s 上限**、**软触发**。
3. **物理层识别**：最小游程 104 µs ⇒ 9600 baud；937 µs 簇 = 9 位 = 一整个 8N1 帧。
4. **协议逆向**：帧头切帧 → 逐字节 uniq 统计 → 浮点字段扫描 → 定位各字段。
5. **标定**：用同款 F103 做**可控 RGB 光源**（含单次脉冲/循环两种模式），
   配合表显读数做**三轮逐位对照**，把 µW/cm² 的量纲钉死。
6. **校验和**：穷举 65536 个 CRC-16 多项式，两轮独立数据唯一命中 CRC-16/MODBUS；
   再用主机命令的末两字节交叉验证。
7. **端到端自证**：F103 当主机读探头 21/21 帧零错误；复现清零命令并验证三个字段同时响应。
8. **设置项排查**：反复开关机 + 逐项改设置，抓到表的完整配置命令集（开机 9 条 + 进测量 3 条）。

全程的原始证据、每一轮实验的设计与判据，都在技能
`nanodla-logic-analyzer/references/case-ls125-uv-meter.md`（17 节）。
