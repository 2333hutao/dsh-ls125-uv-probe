# LS125 ↔ UVALED-X3 完整协议规格

> 所有内容均为**实测**结论，不是推断。验证方式在每节末尾标注。
> 原始证据（17 节、含每轮实验设计与判据）见 DSH 技能
> `nanodla-logic-analyzer/references/case-ls125-uv-meter.md`。

---

## 1. 物理层

| 项 | 值 | 验证 |
|---|---|---|
| 探头线 | **6 芯**：5V + 2×GND（供电地与信号地相通）+ 3 根信号 | 实测 |
| 协议 | **UART 9600 8N1，空闲高** | 最小游程 104 µs = 9600 baud 一位；937 µs 簇 = 9 位 = 一整个 8N1 帧 |
| 信号 1 | **主机 → 探头**（命令） | 内容是恒定轮询命令 |
| 信号 2 | **探头 → 主机**（数据） | 内容是随读数变化的测量帧 |
| 信号 3 | **静态控制线**（表在驱动它，接表时恒低） | **可悬空** |
| 轮询周期 | **500 ms** | 240 s 抓取 481 帧，间隔 0.500 s |

**信号 3（原 LA 的 D4）的四重排除**：接表时恒低而探头正常通信（否定"低有效复位"）；
脱表后悬空变高而探头照常回帧（否定"高有效复位"）；用跳线持续拉低不影响累积量；
接表时按 `DEL` 全程零脉冲（否定"按键脉冲复位"）⇒ **与复位/清零完全无关，悬空即可**。

## 2. 主机 → 探头：命令

**所有命令都以 `AB` 开头、末尾 2 字节是 CRC-16/MODBUS（小端）。**

### 2.1 轮询（必需，每 500 ms 一次）

```
AB 20 60 00 14 00 | 89 07
└─ 6 字节载荷 ────┘ └ CRC ┘
```

### 2.2 清零

```
AB 21 20 00 02 00 01 00 | 3D 8A
└──── 8 字节载荷 ──────┘ └ CRC ┘
```

按表上的 `DEL` 时，表在**一次轮询之后紧跟**这条命令发出（抓到的"帧"是 18 字节 = 8+10）。

**清零的三个效果**（用自制 F103 复现验证）：

| 字段 | 清零前 | 清零后 |
|---|---|---|
| 累积能量（10–13） | 2,883,738 | **4,101.7**（归零并重新累加） |
| 最小值（18–21） | 0.000 | **9088.459**（重置为当前读数） |
| 计时（14–15） | 3182 | **4**（归零重新计时） |

### 2.3 开机配置序列（**自制主机不需要发**，仅作记录）

每次开机，表依次下发 **9 条**（每次完全相同）：

```
AB 21 08 00 06 00 95 19 87 01 6A 00 FB F7   14B 写
AB 20 0E 00 02 00 9B 8F                      8B 读
AB 20 05 00 12 00 94 6B                      8B 读
AB 40 24 00 00 00 06 00 4F 40               ┐
AB 40 40 00 00 00 0A 00 42 64               │
AB 40 54 00 00 00 06 00 44 70               │ AB 40 家族 6 条
AB 40 60 00 00 00 06 00 40 04               │ （设置/标定写入）
AB 40 14 00 00 00 04 00 4B D0               │
AB 40 80 00 00 00 03 00 55 34               ┘
```

### 2.4 进入测量模式时的序列

```
AB 70 60 00 00 00 06 00 00 0A 00 01 E1 E6 BE EB   16B
AB 70 80 00 00 00 03 00 <3 字节参数> 77 EF        13B
AB 21 20 00 02 00 01 00 3D 8A                     10B ← 清零
```

**★ 表进入测量模式时会自动清零** ⇒ 表上"距上次清零的时间"从那一刻起算
（用户照片里的 `1.0 S` / `1.5 S` / `2.0 S` 与此吻合）。

### 2.5 命令字节族规律

| 首字节 | 形态 | 推测含义 |
|---|---|---|
| `AB 20 xx ...` | 6B 载荷 + CRC = 8B | **读/查询**（轮询即 `AB 20 60 00 14 00`） |
| `AB 21 xx ...` | 8B 载荷 + CRC = 10B | **写**（`AB 21 20 ...` = 清零） |
| `AB 40 xx ...` | 8B 载荷 + CRC = 10B | **写设置/标定** |
| `AB 70 xx ...` | 11–14B 载荷 + CRC | **进入测量/量程类** |

**`AB 70 80` 载荷的第 9–11 字节会变**：`01 7E 80`(0x017E80=98944) ↔ `00 BF 40`(0x00BF40=48960)，
**约 2 倍**，疑似**量程/增益**（单位是 1000 倍关系，不是 2 倍）。

## 3. 探头 → 主机：28 字节定长数据帧

| 偏移 | 类型 | 含义 | 单位 | 验证方式 |
|---|---|---|---|---|
| 0–5 | — | 帧头 `AB 20 60 00 14 00`（与轮询命令前 6 字节相同） | — | 全帧一致 |
| 6–9 | float LE | **实时辐照度** | **µW/cm²** | 表显最大值**三轮逐位吻合**（3284.0359↔3.2840 / 3286.2664↔3.2863 / 3290.4019↔3.2904） |
| 10–13 | float LE | **累积能量** | **µJ/cm²** | `d/dt == 辐照度`；清零归零；量级吻合（0.1%） |
| 14–15 | uint16 LE | **距上次清零的时间** | **×0.1 s** | 每帧 +5；清零归零；定量核对 95×0.1 s=9.5 s ≈ 10 s；**表上就有此显示** |
| 16–17 | 2B | 恒 0，含义未定 | — | 切单位后仍为 0 ⇒ **非单位/量程字段** |
| 18–21 | float LE | **最小值 `P_MIN`** | µW/cm² | 清零后跳成当前读数；长期 0 时与表显 `P_MIN 0.0000` 一致；**最大值不可能长期为 0** |
| 22–25 | float LE | **平均辐照度 `P_AVG`** | µW/cm² | 稳态下与实时值相等（差 0.4%） |
| 26–27 | uint16 LE | **CRC-16/MODBUS**(over 0–25) | — | 见下 |

**关键性质**

- **帧内数值永远是 µW/cm² / µJ/cm²，不随表上的单位档变化。**
  证据：单位切到 mW/cm² 时，表显 `P 9.0948 mW/cm²`，帧内 `f6 ≈ 9094.8`；表显 `E 9.3203 mJ/cm²`，
  帧内 `f10 ≈ 9320` ⇒ 一一对应。
- **最大值 `P_MAX` 不在帧里**（16–17 恒 0、其余字段均已定性）⇒ 表自己从实时流统计。
  **自制主机同理：自己取历史最大/最小/平均即可。**
- **探头只在被轮询时回帧**（用 openocd `halt` 暂停主机后，两条线双双 0 边沿）。
- **不需要任何上电握手**：自制主机一开轮询探头即正常应答。
- 表的设置（`Units` / `Energy display` / `Standard Selection` / `Auto off`）**都不进帧**；
  `Energy display = NO` 时帧里 `f10` 照常有值 ⇒ 纯显示开关。

## 4. 校验和：CRC-16/MODBUS

```
poly 0x8005（反射实现 0xA001）
init 0xFFFF
LSB-first (refin/refout)
xorout 0x0000
覆盖范围：字节 0 .. 25
存放：字节 26..27，小端
```

**验证**：对两轮独立抓取（238 帧 / 148 帧）穷举 65536 个多项式 × 两种位序 × 3 个初值 × 4 种覆盖范围，
**唯一命中同一条**；再用主机命令交叉验证：

| 命令 | 前 N 字节的 CRC | 小端 | 实际末两字节 |
|---|---|---|---|
| 轮询 `AB 20 60 00 14 00` | 0x0789 | `89 07` | `89 07` ✓ |
| 清零 `AB 21 20 00 02 00 01 00` | 0x8A3D | `3D 8A` | `3D 8A` ✓ |

## 5. 参考实现（C，可直接移植）

```c
/* ---- CRC-16/MODBUS ---- */
static uint16_t crc16_modbus(const uint8_t *d, uint32_t n) {
    uint16_t crc = 0xFFFF;
    for (uint32_t i = 0; i < n; i++) {
        crc ^= d[i];
        for (int k = 0; k < 8; k++)
            crc = (crc & 1) ? (uint16_t)((crc >> 1) ^ 0xA001) : (uint16_t)(crc >> 1);
    }
    return crc;
}

/* ---- 主机每 500 ms 发一次 ---- */
static const uint8_t POLL[8]  = {0xAB,0x20,0x60,0x00,0x14,0x00,0x89,0x07};
static const uint8_t CLEAR[10]= {0xAB,0x21,0x20,0x00,0x02,0x00,0x01,0x00,0x3D,0x8A};

/* ---- 解析 28 字节回帧 ---- */
static float f32le(const uint8_t *p) {
    union { uint32_t u; float f; } v;
    v.u = (uint32_t)p[0] | ((uint32_t)p[1]<<8) | ((uint32_t)p[2]<<16) | ((uint32_t)p[3]<<24);
    return v.f;
}

int ls125_parse(const uint8_t *f, float *irradiance_uW, float *energy_uJ,
                float *average_uW, float *minimum_uW, uint16_t *since_clear_100ms)
{
    for (int i = 0; i < 6; i++) if (f[i] != (uint8_t[]){0xAB,0x20,0x60,0x00,0x14,0x00}[i]) return -1;
    uint16_t crc = crc16_modbus(f, 26);
    if (f[26] != (crc & 0xFF) || f[27] != (crc >> 8)) return -2;
    *irradiance_uW      = f32le(&f[6]);
    *energy_uJ          = f32le(&f[10]);
    *minimum_uW         = f32le(&f[18]);
    *average_uW         = f32le(&f[22]);
    *since_clear_100ms  = (uint16_t)(f[14] | (f[15] << 8));
    return 0;
}
```

**单位换算**：表显 `mW/cm²` = `irradiance_uW / 1000`；表显 `mJ/cm²` = `energy_uJ / 1000`。

**已实测的嵌入式参考实现**：`firmware/f103_probe/main.c`
（9600 8N1、轮询、CRC 校验、四字段解析、调试输出；**21/21 帧、零 CRC 错、零超时**）。
